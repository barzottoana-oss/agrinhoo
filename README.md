# agrinho 2026
É uma página da web sobre o Projeto Agrinho que tem como fundo a foto de um campo agrícola cobrindo toda a tela. No centro, há uma caixa de texto elegante com efeito transparente onde fica uma breve explicação sobre o projeto. O grande destaque é um contador animado que mostra uma porcentagem subindo na tela, feito para chamar a atenção de quem visita o site.
